# Project Memory

## Framework & Structure
- Uses React Router v7 with file-based routing
- Package manager: pnpm
- UI: Radix UI components with Tailwind CSS
- Medical dashboard theme

## Conventions
- Components in `~/components/` with TypeScript
- Routes in `app/routes/` directory
- Uses `~` alias for app directory imports
- Sidebar navigation with medical-themed icons and navigation

## Key Components
- AppSidebar: Main navigation component
- SidebarHeader: Top header with search and controls
